1목표 (말로 적기)

매월 말일, 주요 거래처 50곳의 ERP 매출 채권 잔액과 거래처가 메일로 보낸 회신 잔액을 비교해 줘. 차이가 나는 곳은 원인 후보를 찾고, 거래처에 보낼 확인 메일 초안을 만들어 줘.
  1. AI가 단계로 정리 ERP에서 거래처별 채권 잔액 조회 → 메일함에서 회신 잔액 추출 → 비교

  3. 대사 보고서(엑셀)와 확인 메일 초안 작성 → 메일 발송은 승인 후
