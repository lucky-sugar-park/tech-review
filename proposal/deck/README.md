# 경영진 보고 덱 생성

`../ai-agent-platform-proposal.pptx`(24장, 발표자 노트 포함)를 만드는 스크립트입니다. 숫자와 출처는 근거 문서 `../ai-agent-platform-proposal.md`와 같아야 합니다.

```bash
npm install pptxgenjs
node build_deck.js                      # ../ai-agent-platform-proposal.pptx 생성
```

- 투자·효과 숫자(17번 장표)는 근거 문서 8장의 가정으로 계산했습니다. 회사 실제 숫자로 바꾸면 `build_deck.js`의 차트 값과 표도 함께 고칩니다.
- 테마 색상은 생성 후 테마 적용 도구로 입힙니다(`APPLY_THEME` 환경 변수). 그 도구가 없는 환경에서 다시 만들면 기본 Office 팔레트로 보이므로, 문구만 고칠 때는 PowerPoint에서 직접 수정하는 편이 간단합니다.
- 글꼴은 맑은 고딕(Malgun Gothic)입니다.

## v2 (`build_deck_v2.js` → `../ai-agent-platform-proposal-v2.pptx`, 27장, 최신)

v1은 그대로 두고 따로 만든 버전입니다. 비용·효과 숫자는 근거 문서 8장과 계산 엑셀의 최신 가정(파일럿 0.95억 원, 1년차 4.6억 원)과 같습니다. v1은 이전 가정(파일럿 3.4억 원, 1년차 7.8억 원)입니다.

- 표지 하단 부서: 회계·영업·생산·보전·품질·구매·개발·일상 업무
- 2번 "한 장 요약: 문제점 분석 및 제안" (현행 문제점 AS-IS → 제안 TO-BE, v1의 당위성 장표를 합침)
- 대표 시나리오: 3가지 요약표(품질·영업·회계), 품질 클레임 상세, 내 에이전트, 관리 절차
- 문제: 지금의 방식(6단계 중 AI는 1단계, "느리다·반쪽이다·위험하다"), MCP 설명(글로벌 표준), 우리 데이터용 도구가 없다는 점
- 기대 효과: 같은 인원으로 더 많은 일을, 더 좋은 품질로 (처리 능력·품질·속도)
- 실행 계획: 1단계 파일럿 약 0.95억 원(1억 이하), Go/No-go 지표에 처리 시간 50% 단축
- 부록: 투자와 효과, 구축 방식, 예상 질문과 답변 (v1의 "오늘 결정을 요청드립니다" 장표는 뺐습니다)
