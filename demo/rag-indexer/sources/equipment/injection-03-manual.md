# 3호기 사출기 운전·보전 매뉴얼

## 1. 알람 코드표

| 코드 | 내용 | 1차 조치 |
|---|---|---|
| E-105 | 금형 온도 상한 초과 | 냉각수 밸브 개도와 유량을 확인한다 |
| E-217 | 실린더 히터 단선 의심 | 히터 저항을 측정하고 기준(42~48Ω) 밖이면 히터를 교체한다 |
| E-302 | 형체력 부족 | 유압 압력을 확인하고 토글 윤활 상태를 점검한다 |
| E-410 | 이젝터 위치 이상 | 이젝터 리밋 스위치와 센서 배선을 점검한다 |

## 2. 실린더 히터 교체 절차

1. 메인 전원을 차단하고 LOTO(잠금·표지)를 실시한다.
2. 실린더 온도가 60℃ 이하로 내려갈 때까지 기다린다.
3. 히터 커버를 열고 단자 배선에 번호를 표시한 뒤 분리한다.
4. 새 히터를 장착하고 클램프를 균일하게 조인다.
5. 배선을 원래 번호대로 연결하고 절연 저항을 확인한 뒤 시운전한다.

## 3. 정기 점검

진동은 매주 월요일 모터 베어링 하우징에서 측정한다. 진동값이 4.5 mm/s를 넘으면 보전팀에 알리고, 7.1 mm/s를 넘으면 운전을 멈춘다.
