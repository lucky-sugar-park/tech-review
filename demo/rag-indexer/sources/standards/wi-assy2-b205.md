# B-205 브래킷 조립 작업표준서

## 1. 작업 순서

1. 하우징을 지그에 고정하고 방향 표시가 위로 오는지 확인한다.
2. 브래킷을 하우징 홈에 맞춰 끼운다.
3. M6 볼트 4개를 대각선 순서로 체결한다. 체결 토크는 9.0 N·m이다.
4. 토크 확인 후 마킹펜으로 체결 표시를 한다.

## 2. 품종 교체 절차 (C-310 → B-205)

1. 이전 품목 잔량을 모두 회수하고 MES에서 작업지시를 종료한다.
2. 조립 지그를 B-205용(JIG-B205)으로 교체한다.
3. 토크 렌치 설정값을 9.0 N·m로 바꾸고 시험 체결 3회로 확인한다.
4. 초품 1개를 품질팀에 보내 검사 합격 후 양산을 시작한다.

## 3. 품질 확인 항목

| 항목 | 기준 | 주기 |
|---|---|---|
| 볼트 체결 토크 | 9.0 ± 0.5 N·m | 2시간마다 5개 |
| 브래킷 유격 | 0.2 mm 이하 | 2시간마다 5개 |
| 외관 긁힘 | 없을 것 | 전수 |
