# MES 사용 매뉴얼

## 1. 작업지시

### 1.1 작업지시 순서 변경

작업지시 순서는 [생산관리] > [작업지시 현황] 화면에서 바꿉니다. 대상 작업지시를 선택하고 [순서 변경] 버튼을 눌러 우선순위를 입력합니다. 이미 시작된 작업지시는 순서를 바꿀 수 없습니다. 순서 변경은 생산관리 권한이 있는 사용자만 할 수 있고, 변경 이력은 자동으로 남습니다.

### 1.2 작업지시 분할

수량이 많은 작업지시는 [분할] 버튼으로 두 개로 나눌 수 있습니다. 분할된 작업지시는 원래 번호 뒤에 -1, -2가 붙습니다.

## 2. 실적과 비가동 입력

### 2.1 비가동 사유 입력

설비가 10분 이상 멈추면 POP 단말에 비가동 입력 창이 뜹니다. 비가동 사유 코드는 다음 중에서 고릅니다. 설비 고장은 D10, 금형·치공구 문제는 D20, 자재 대기는 D30, 품종 교체는 D40, 계획 정지는 D50입니다. 어느 코드에도 맞지 않으면 D90(기타)을 고르고 내용을 꼭 적습니다.

### 2.2 불량 입력

불량은 [실적 입력] 화면의 [불량] 탭에서 불량 유형과 원인을 고르고 수량을 입력합니다. 사진을 첨부하면 품질팀이 원인을 확인하기 쉽습니다.
